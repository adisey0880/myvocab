# myvocab — словарь английского для узбекоговорящих

Контекстный документ проекта. Передай его вместе с исходниками в новый чат, чтобы продолжить работу без объяснений с нуля.

## 1. Для кого и зачем

Пользователь — **Умиджон**, носитель узбекского, изучает английский после работы (~2 часа в день). Elementary (A2) пройден, с 15.09.2026 занимается по **Pre-Intermediate (B1)**, цель — B1/B2. Занимается с преподавателем, который выдаёт лексику пачками по темам с кодами уроков (6E, 6F, 6G, 6H, 7A, 7B, 7C/7D...).

**Задача сайта:** повторять выученные слова с правильным произношением, в любой момент и с любого устройства. Основной сценарий — телефон.

Рабочий язык интерфейса — узбекский (латиница). Пользователь пишет на узбекской кириллице и по-русски.

## 3.1 Неправильные глаголы (`verbs.js`)

Отдельный раздел, переключается вкладками **`So'zlar` / `Fe'llar`** слева от поиска. Своя структура и свой прогресс (`learnedVerbs`), ключ — первая форма в нижнем регистре.

Массив `VERB_GROUPS`, 10 групп в том же порядке, что на бумаге у преподавателя (жирные строки в таблице = начало группы):

| Группа | Что объединяет | Глаголов |
|---|---|---|
| 1 · A–A–A | все три формы одинаковы | 7 |
| 2 · -t / -d | lend–lent, keep–kept | 19 |
| 3 · -ought / -aught | bring–brought, teach–taught | 6 |
| 4 · A–B–B | sell–sold, make–made | 12 |
| 5 · -oke / -oken | break–broke–broken | 5 |
| 6 · -ove / -iven | drive–drove–driven | 7 |
| 7 · -en | eat–ate–eaten | 6 |
| 8 · -ew / -own | blow–blew–blown | 7 |
| 9 · i–a–u | drink–drank–drunk | 6 |
| 10 · maxsus | be, do, go, come | 8 |

**Формат записи (10 полей, три формы через `|`):**

```js
["burn|burnt|burnt", "burn|burned|burned",     // формы BrE, формы AmE (или null)
 "/bɜːn/|/bɜːnt/|/bɜːnt/", "byon|byont|byont", "бён|бёнт|бёнт",   // BrE: IPA, латиница, кириллица
 "/bɝːn/|/bɝːnd/|/bɝːnd/", "byorn|byornd|byornd", "бёрн|бёрнд|бёрнд", // AmE
 "Гореть, жечь", "Yonmoq, yondirmoq"]
```

Второе поле нужно там, где британский и американский варианты пишутся по-разному: `burnt/burned`, `learnt/learned`, `smelt/smelled`, `dreamt/dreamed`, `got/gotten` — переключатель `Aksent` меняет и написание, и озвучку.

**Отличия в интерфейсе:**
- Карточка — три колонки V1 / V2 / V3, у каждой своя IPA и транскрипция
- Озвучка читает все три формы подряд: «go, went, gone»
- Режим `UZB → ENG` размывает только V2 и V3, оставляя V1 — это классическое упражнение
- Тренировка: показать V1 → вспомнить V2 и V3 (или наоборот: перевод → все три формы)
- Переключатель `Sana / Mavzu` в этом разделе скрыт — он относится только к словарю

## 3.2 Примеры-предложения (`sentences.js`)

Отдельный словарь `SENTENCES`, ключ — то же нормализованное слово, что и в прогрессе (нижний регистр, апострофы приведены к `'`). Поэтому одна запись обслуживает и словарь, и глаголы.

```js
"instruction": ["Read the instructions before you start.",
                "Boshlashdan oldin ko'rsatmalarni o'qing.",
                "Прочитайте инструкцию перед началом."]
```

- Предложение показывается **на карточке** (английский + узбекский) и **в тренировке** после ответа (плюс русский).
- Изучаемое слово выделяется жирным акцентным цветом. Подсветка терпима к формам: `make friends` → «**makes friends**», `hurdles` → «**hurdle**», а для фразовых глаголов подтягиваются формы из `verbs.js`: `fall off` → «**fell off**», `be` → «**was**». Покрытие подсветки — 507/507 и 83/83.
- Слова без предложения просто не показывают блок — файл можно дополнять постепенно, ничего не ломая.
- Режимы скрытия работают и здесь: `ENG → UZB` размывает перевод предложения, `UZB → ENG` — само английское предложение.

## 3.3 Тренировка правописания (`✍️ Yozish`)

Четвёртый вариант в настройке «Направление». Вопрос — перевод, ответ — набрать английское слово руками.

- Поле ввода с `spellcheck="false"`, `autocorrect="off"`, `autocapitalize="off"` — иначе телефон исправляет слово за пользователя.
- Проверка нечувствительна к регистру, лишним пробелам и типу апострофа; принимаются **оба варианта написания** (`realise`/`realize`).
- Для глаголов — **два поля: V2 и V3** (классическое упражнение), проверяются независимо.
- `💡 Yordam` показывает первую букву и длину: `P _ _   _ _`.
- При ошибке видно, что набрал пользователь, и правильное написание с подсветкой неверных букв: ~~brout~~ → **brou`ght`**.
- Enter: первый раз — проверить, второй — перейти дальше. Результат ставит приложение, кнопок «Qiyin/Oson» после проверки нет (раньше можно было нажать «Oson» даже после ошибки). Ошибка → слово вернётся в конец сессии. Space не перехватывается — он нужен для ввода.
- В итоговой статистике появляется строка «X/Y to'g'ri yozildi».

## 3.4 Интервальное повторение (SRS)

Вместо флага «выучено / не выучено» у каждого слова своя запись:

```js
progressWords: { "instruction": { box: 2, due: "2026-09-10", wrong: 0, st: 15 } }
```

| Поле | Смысл |
|---|---|
| `box` | коробка 0–5. `0` — ещё не выучено, карточка показывается как «Yangi» |
| `due` | дата следующего повторения, `YYYY-MM-DD` |
| `wrong` | сколько раз ошибся в тренировке (в т. ч. в правописании) |
| `st` | битовая маска пройденных упражнений: 1 Kartochka, 2 Test, 4 Yozib mashq, 8 Eshitib yozish (см. 3.8) |

**Интервалы по коробкам:** `1 → 3 → 7 → 21 → 60` дней (`SRS_STEPS`).

- **Попасть в коробку 1** можно только пройдя все 4 упражнения (раздел 3.8). Ручной отметки ✓ на карточке больше нет.
- **Верный ответ** для слова в повторении (`box ≥ 1`) → коробка +1, `due` = сегодня + интервал новой коробки.
- **Ошибка** → коробка обнуляется, `wrong += 1`, слово возвращается в конец сессии; снимается отметка только **того упражнения**, в котором ошибся.

**Миграция.** Старый список `learnedWords` автоматически превращается в записи `{ box: 2, due: сегодня + 3 }` — то есть уже выученное не теряется, но и не считается «навечно выученным». Формат помечен как `v: 5` (v4 → v5: у всех слов с `box ≥ 1` появляется `st: 15`, то есть уже выученное считается пройденным 4/4); ключ в `localStorage` остался прежним.

**Два новых чипса** появляются в ленте уроков сами, когда в них что-то есть:

- **🔁 Takror N** — слова, у которых `due <= сегодня` (`box >= 1`). Это план на день.
- **⚠️ Qiyin N** — слова, с которыми **сейчас** есть проблемы: две и более ошибки (`HARD_AT = 2`) **и** коробка ниже третьей (`HARD_OUT = 3`).

  Второе условие важно: список — это текущее состояние, а не история. Как только слово доходит до третьей коробки (недельный интервал), оно само уходит из списка, даже если когда-то было десять ошибок. Иначе список бы только рос и со временем потерял смысл.

Чипсы работают как обычный фильтр урока, а тренировка с источником **«Joriy filtr»** берёт именно их — отдельных настроек не потребовалось.

## 3.5 Дневная цель и серия дней

```js
daily: { goal: 20, days: { "2026-09-07": 14 }, todayKeys: [...], day: "2026-09-07" }
```

- Слово засчитывается **один раз в день** — при любом ответе в тренировке (`todayKeys` не даёт посчитать дважды).
- В шапке — пилюля **🔥 3 · 14/20**: слева серия дней, справа сегодняшний прогресс. Фон пилюли заливается по мере выполнения, при достижении цели становится зелёной.
- **Серия** — количество идущих подряд дней с любой активностью, считается от сегодня (или от вчера, если сегодня ещё не начинали). Пропустил день — серия обнуляется.
- Цель меняется в подвале: `Kunlik maqsad: 10 / 20 / 30 / 50`.
- История хранится за последние 90 дней и попадает в резервную копию.

## 3.6 Озвучка примеров

Кнопка 🔊 в блоке предложения — на карточке и в тренировке. Читает предложение целиком тем же голосом и с тем же акцентом, что и слово. На карточке нажатие не «проваливается» в саму карточку (`stopPropagation`), поэтому размытие не снимается и слово отдельно не проговаривается.

## 3.7 Учебный центр: Kartochka · Test · Yozib mashq · Eshitib yozish

Над списком слов — панель, которая работает с **тем, что сейчас на экране**: выбранный урок, «🔁 Takror», «⚠️ Qiyin», «Hammasi», фильтр статуса и поиск. Одно нажатие — и начинается занятие, без окна настроек.

- **Заголовок** — название набора (`7 G, 7 H`, `🔁 Bugungi takror`), **подзаголовок** — дата, количество, сколько выучено и сколько ждёт повторения. На «Hammasi» написано «463 ta so'z (takrorlarsiz)»: слова, повторяющиеся в разных уроках, попадают в занятие один раз, поэтому число меньше 507 карточек в шапке.
- **Soni: 10 · 20 · Hammasi** — размер занятия, запоминается (`hubCount`).
- **Порядок слов** (`orderForSession`): сначала те, у кого подошёл срок повторения → слова, ещё **не прошедшие это упражнение** (трудные → близкие к повторению → новые) → уже прошедшие его → выученные. В «Kartochka» внутри каждой группы сохраняется порядок урока, в остальных режимах — перемешивание.
- **Кнопки пронумерованы 1–4** (от лёгкого к трудному), под каждой — «N ta qoldi»: сколько невыученных слов набора ещё не прошли это упражнение. Первое незавершённое упражнение подсвечено как следующий шаг.

| Режим | Вопрос | Ответ | Для глаголов |
|---|---|---|---|
| 1 🃏 **Kartochka** | слово, звучит сразу | Space — перевод и пример; `1` Qiyin / `2` Oson | V1 → V2, V3 |
| 2 ✅ **Test** | слово (EN→UZ) или перевод (UZ→EN), случайно | 4 варианта, клавиши `1–4` | V1 → выбрать «V2 · V3» |
| 3 ✍️ **Yozib mashq** | перевод | набрать английское слово | поля V2 и V3 |
| 4 🎧 **Eshitib yozish** | ничего не показано, только звук (🔊 и 🐢 медленно) | набрать услышанное, Enter | три поля V1, V2, V3 |

Детали:

- **Подсказка в диктанте — в два шага:** сначала значение слова, затем первая буква и длина.
- **Варианты теста** берутся из того же урока (так сложнее и полезнее); совпадающие по смыслу отбрасываются — «Accept» и «Receive» оба «Qabul qilmoq» и вместе не появятся. Для глаголов — из той же группы: `think` → `thought · thought / caught · caught / taught · taught / fought · fought`.
- **Test:** верный ответ — переход дальше сам через ~1 с; ошибка — ждёт Enter, чтобы успеть прочитать правильный вариант.
- `was/were` принимается и целиком, и по отдельности.
- Все режимы пишут в SRS, список «Qiyin» и дневную цель.

**Экран итогов** показывает: сколько слов пройдено, сколько прошли упражнение, сколько перешли в «Takror», ошибок, результат правописания или теста — и строку «Qolgan mashqlar: ✅ Test — 12 ta · …» с подсказкой, сколько словам остался один шаг. Кнопки:

- **→ 2. ✅ Test (N ta)** — главная кнопка: следующее упражнение **с теми же словами** (`nextExercise`). Берётся следующее по порядку 1→2→3→4 (после 4-го — по кругу), в котором кто-то из этих слов ещё не прошёл; в занятие попадают только такие слова. Если все слова уже выучены (например, «Takror»), — просто следующее по порядку со всеми словами; после «Eshitib yozish» кнопки нет. Так партия слов проходит все 4 упражнения подряд, не возвращаясь в список;
- **🔁 Xatolar (N)** — пройти заново только ошибочные слова в том же режиме;
- **↻ Yana** — новое занятие по тому же набору (порядок пересчитывается);
- **← Ro'yxatga** — вернуться к списку. После выхода список и чипсы перерисовываются: пройденные слова исчезают из «Takror».

**Окно упражнения закрывается только кнопкой ✕** (или «Ro'yxatga» на экране итогов): клик по фону и `Esc` его не закрывают — раньше случайное касание мимо карточки обрывало занятие. Окно настроек «Mashg'ulot» по-прежнему закрывается кликом по фону.

**Тосты** при открытом окне показываются сверху, чтобы не закрывать кнопки. Тост «4/4, Takrorga qo'shildi» всегда один (новый заменяет предыдущий), на экране итогов убирается — там есть строка «N ta Takrorga qo'shildi».

Кнопка **Mashg'ulot** с окном настроек осталась для нестандартных занятий (UZB → ENG, «Aralash», фильтр по статусу); в ней тоже есть «Eshitib yozish» и «Test». Оба входа используют один движок сессии (`startSession`). UZB → ENG и «Aralash» засчитываются как упражнение «Kartochka».

## 3.8 Четыре упражнения — ворота в повторение

**Проблема.** Раньше одно нажатие «Oson» на карточке сразу делало слово выученным. Но карточка — самооценка: «узнаю» ≠ «знаю».

**Правило.** Слово попадает в «🔁 Takror» (коробка 1, `due` = завтра) только после того, как пройдены **все 4 упражнения**. Порядок свободный, рекомендуемый — от лёгкого к трудному: узнать (Kartochka) → выбрать (Test) → вспомнить и написать (Yozib mashq) → услышать и написать (Eshitib yozish). Логика самого «Takror» не изменилась.

| Упражнение | Когда засчитано |
|---|---|
| 🃏 Kartochka (а также UZB → ENG, Aralash) | нажата «Oson» |
| ✅ Test | выбран верный вариант |
| ✍️ Yozib mashq | написано верно, буквы подсказки не открывались |
| 🎧 Eshitib yozish | написано верно, буквы не открывались (первая подсказка — только значение — разрешена) |

- **Ошибка** в упражнении снимает отметку только с него, остальные сохраняются; `wrong += 1` (может попасть в «⚠️ Qiyin»).
- **Верно, но с открытыми буквами** — нейтрально: не засчитано и не ошибка, слово повторяется в конце сессии.
- **Ошибка в повторении** (`box ≥ 1`): как и раньше, коробка обнуляется и слово уходит из «Takror», но снимается только отметка этого упражнения — достаточно пройти его заново.
- **Инвариант:** `box ≥ 1` ⇔ `st = 15`.
- Реализация: `STAGES`, `DIR_STAGE`, `recordAnswer(key, stage, result)` с результатом `ok | bad | hint`; тестовые режимы фиксируют результат сразу при проверке (`applyResult`), кнопка «Keyingi» только переходит дальше (`advanceChecked`).

**Что видит пользователь:**

- на каждой карточке списка внизу — 4 значка (пройденные цветные) и подпись: «Yangi · 4 ta mashq kerak», «2/4 · qoldi: Yozib mashq, Eshitib yozish», «3/4 · oxirgisi: Eshitib yozish → Takror», «🔁 Takror: 14.09.2026», «⭐ Mustahkam»;
- в окне тренировки те же значки под ответом; изменённый значок «подпрыгивает» (или краснеет при ошибке), при 4/4 — тост «🎉 bright — 4/4, Takrorga qo'shildi»;
- фильтр статуса: **Barchasi / Yangi / O'rganilmoqda / Yodlangan** («Yangi» — ни одного упражнения, «O'rganilmoqda» — 1–3);
- в подзаголовке центра: «3 yangi · 10 o'rganilmoqda · 6 yodlangan».

## 3.9 Модули: Elementary и Pre-Intermediate

У каждой группы в `words.js` есть поле `level`: `"elem"` (A2) или `"preint"` (B1). Каждый уровень — отдельный модуль со своими уроками.

- **Переключатель** `A2 Elementary | B1 Pre-Intermediate` — в первой строке шапки, перед «Mashg'ulot» (на телефоне: `A2 Elem | B1 Pre-Int`). Для «Fe'llar» скрыт: неправильные глаголы общие.
- **В модуле видно только его:** чипсы уроков, «Hammasi», счётчик в шапке и на кнопке «So‘zlar», учебный центр («Pre-Intermediate: barcha so'zlar»), источник «Hammasi / Tanlangan dars» в окне «Mashg'ulot», поиск, варианты теста.
- **«🔁 Takror» и «⚠️ Qiyin» — из всех модулей сразу** (заголовок «· A2 + B1», у урока в списке — метка модуля: «05.09.2026 · A2»). Иначе, перейдя на B1, легко забыть повторять слова A2.
- **Статус слова общий:** ключ — само слово, поэтому `Accept`, выученный в A2, в B1 сразу отмечен выученным.
- **Каждый модуль помнит свой урок** (`lessonByLevel`); урок другого модуля автоматически сбрасывается на «Hammasi».
- **Поиск:** если в текущем модуле ничего нет, а в другом есть — кнопка «Elementaryda N ta topildi →».
- По умолчанию открыт Pre-Intermediate (`level` сохраняется в состоянии).
- В предложениях `smb` / `sth` в ключе подсвечивают любое слово: «**Give me a call**» для `Give smb a call`.
- Подсветка учитывает удвоение последней согласной: `kid` → «**kidding**», `slip` → «**slipped**».

## 4. Функции интерфейса

- **Поиск** — по всем полям сразу: англ. (BrE/AmE), IPA, обе транскрипции, рус., узб. Разные апострофы (`'` `’` `ʻ`) считаются одинаковыми. Ввод с задержкой 120 мс
- **Фильтр** — переключатель `Sana` / `Mavzu`; чипсы под ним фильтруют по конкретному уроку и показывают прогресс `12/50`
- **Yozuv** — `Lotin` / `Кирилл`, переключает колонку произношения
- **Aksent** — `American` / `British`; меняет IPA, транскрипцию, написание слова (Traveller/Traveler) **и голос озвучки**
- **Sekin** — замедленное произношение (rate 0.55 вместо 0.9)
- **Скрытие (3 режима)** — `Yashirish: yo'q` → `ENG → UZB` → `UZB → ENG`. Клик по карточке снимает размытие и озвучивает
- **▶ Hammasi** — последовательная озвучка всех видимых карточек
- **🎯 Mashg'ulot** — флеш-карточки: 5 настроек (источник / количество / направление / порядок / статус), живой счётчик доступных слов, «Qiyin» **возвращает слово в конец сессии**. Засчитывание упражнений — по правилам раздела 3.8. В конце — статистика
- **Статус слова** — 4 значка упражнений на карточке и фильтр (Barchasi / Yangi / O'rganilmoqda / Yodlangan); ручной отметки нет
- **Резервная копия прогресса** — кнопки в подвале: экспорт в JSON и импорт (объединяет, ничего не теряя; понимает и старый формат ключей)
- **Сохранение состояния** в `localStorage` (`myvocab_settings_v3`, автомиграция с `v2`)
- **PWA** — офлайн, установка на домашний экран (иконки PNG 192/512, maskable)
- **Тема** — тёмная / светлая, без вспышки при загрузке
- **Клавиатура** — `/` поиск, `Esc` очистка поиска / закрытие окна настроек (окно упражнения — только ✕), `Space` показать ответ, `1` сложно, `2` легко, стрелки внутри переключателей

**Раскладка шапки:** на десктопе все переключатели (Yashirish, Hammasi, Sekin, Yozuv, Aksent, Status, Filtr) стоят в **одну строку** — блок `.adv` объявлен `display: contents`, поэтому он не создаёт своей строки. На мобильном (< 600 px) `.adv` прячется за кнопкой-«ползунками» рядом с поиском: свёрнутая шапка занимает ~190 px вместо 450 px, состояние запоминается.

**Смена темы:** на время переключения на `<html>` вешается класс `.theme-switching`, который глушит все `transition`. Без него элементы меняли цвет с разной скоростью и ~0,3 с висели в «полупереходном» состоянии. Все цвета живут в переменных (включая `--overlay`, `--header-bg`, `--badge-bg`, `--card-sheen`, `--shadow-lg`, `--accent-2`); хардкод-цветов, зависящих от темы, в файле нет. Для залитых поверхностей (чипсы, «пилюля», кнопки) используется отдельная переменная `--accent-solid` — она темнее `--accent`, чтобы белый текст на ней давал контраст ≥ 4,5:1. Обе темы проверены на WCAG AA.

## 5. Устройство кода

- `index.html` — разметка; в `<head>` инлайн-скрипт ставит тему до первой отрисовки
- `styles.css` — дизайн-система, две темы, анимации; позиция «пилюли» переключателя задаётся из JS через `transform`
- `words.js` — словарь (507 слов)
- `verbs.js` — неправильные глаголы (83)
- `app.js` — состояние, поисковый индекс (`ITEMS` с готовой строкой для поиска), рендер, TTS, тренировка, модалки с ловушкой фокуса, экспорт/импорт, регистрация SW
- `sw.js` — **network-first**: при наличии сети всегда свежая версия, кэш только как офлайн-резерв. Это принципиально: при старой стратегии «cache-first» новые уроки не доходили до телефона
- `manifest.json`, `icon-*.png` — PWA

**Важно при изменении `sw.js`:** менять константу `VERSION` — по ней чистятся старые кэши.

## 6. Как добавить новый урок

1. В `words.js` в начале массива `GROUPS` добавить объект:

```js
{level:"preint", date:"2026-09-15", topic:"1 A / 1 B", w:[
  ["Word",null,"/ipa-uk/","lat-uk","кир-uk","/ipa-us/","lat-us","кир-us","русский","o'zbekcha"],
]},
```

   `level` обязателен: `"elem"` — Elementary (A2), `"preint"` — Pre-Intermediate (B1). Новый уровень — добавить его в `LEVELS` в `app.js` и кнопку в `#levelSeg`.

2. В `sentences.js` добавить предложение для каждого нового слова (ключ — слово в нижнем регистре).

3. Порядок в массиве не важен — сортировка по дате (новые сверху) происходит сама. Счётчики (212 и т. п.) нигде не прописаны руками, считаются из данных.

**Деплой после изменений:**

```bash
cd ~/Desktop/English/myvocab
git add .
git commit -m "yangi so'zlar"
git push
```

Через ~30 секунд на телефоне появится тост «Yangi so'zlar mavjud» с кнопкой обновления.

## 7. Проверка данных

Быстрый скрипт-валидатор (нет Node — используется Python):

```bash
cd ~/Desktop/English/myvocab && python3 - <<'PY'
import re, json, collections
src = open('words.js', encoding='utf-8').read()
groups = []
for m in re.finditer(r'\{date:"([\d-]+)",\s*topic:"([^"]+)",\s*w:\[', src):
    groups.append({'date': m.group(1), 'topic': m.group(2), 'start': m.end()})
total, bad = 0, []
for i, g in enumerate(groups):
    end = groups[i+1]['start'] if i+1 < len(groups) else len(src)
    rows = [json.loads('['+r[1:-1]+']') for r in re.findall(r'\[(?:[^\[\]]*)\]', src[g['start']:end])]
    total += len(rows)
    print(f"  {g['date']} | {g['topic']:<10} | {len(rows)} ta")
    for w in rows:
        if len(w) != 10: bad.append((g['topic'], w[0] if w else '?', len(w)))
        else:
            for k, v in enumerate(w):
                if k != 1 and not v: bad.append((g['topic'], w[0], f'bo\'sh #{k}'))
print("JAMI:", total, "| XATO:", bad or "yo'q")
PY
```

## 9. Правила работы с проектом

Чтобы новые изменения не ломали то, что уже работает:

1. **Данные отдельно от логики.** Слова, глаголы и предложения — самостоятельные файлы. Новый урок = правка только `words.js`.
2. **Никаких захардкоженных чисел.** Все счётчики (507, 83, 541) считаются из данных. Если число появилось в разметке — это ошибка.
3. **Отсутствие данных не должно ломать экран.** Нет предложения — блок просто не рисуется. Так же должно вести себя любое новое поле.
4. **Ключ прогресса — нормализованное английское слово** (`normText`, нижний регистр, апострофы к `'`). Один и тот же ключ обслуживает словарь, глаголы и предложения.
5. **Меняешь `sw.js` или добавляешь файл — подними `VERSION`** и внеси файл в `CORE_ASSETS`, иначе на телефоне останется старая версия.
6. **После правки данных — прогонять валидатор** из раздела 7 (для `sentences.js` — проверку на 3 элемента в массиве, дубли ключей и кириллицу внутри английского предложения).
7. **Проверять оба раздела** (`So'zlar` и `Fe'llar`) и **обе темы** — тёмную и светлую.
